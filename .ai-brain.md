## API port
3 of 4 classes had Forge API surface (`MisplacedAmbienceSound` is pure
vanilla, untouched):

| File | Change |
|---|---|
| `MisplacedAmbienceMod.java` | Same pattern as the other mods: no-arg `@Mod` constructor → `(IEventBus, ModContainer)`; `Type.COMMON` kept as-is, confirmed against the real 1.21.1 sibling |
| `MisplacedAmbienceConfig.java` | `ForgeConfigSpec(...)` → `ModConfigSpec(...)` |
| `MisplacedAmbienceEvents.java` | `TickEvent.LevelTickEvent` + `Phase.END` → `event.tick.LevelTickEvent.Post`, `event.level` → `event.getLevel()`; `PlayerLoggedOutEvent` repackaged; `RegisterCommandsEvent` repackaged; nested `Mod.EventBusSubscriber(bus=FORGE)` → top-level `@EventBusSubscriber`; **`ClipContext`'s 5th constructor parameter** in `hasLineOfSight()` changed from `null` (`@Nullable Entity`) to `CollisionContext.empty()` — the exact API change RECOVERY.md section 8 documents, confirmed against `peripheralfigure`'s real 1.21.1 decompile (the 1.21.1 sibling of *this* mod doesn't have this code path at all, since the feature it belongs to didn't survive into that jar, so I cross-checked against a different sibling mod that does exercise the same real API instead of guessing) |

## No new judgment calls beyond the ones already established
The `Phase.END`→`.Post` translation reasoning is the same as documented for
hauntedcore/horroractionbar (convergent evidence across siblings). The
`ClipContext`/`CollisionContext.empty()` translation was already flagged as
a known, real API difference by this mod's own prior `.ai-brain.md` note
(sourced from `peripheralfigure`'s decompiled diff) — applied here exactly
as anticipated, not a new discovery.
